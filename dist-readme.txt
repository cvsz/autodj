AutoDJ - Portable Distribution
=====================================

QUICK START
-----------
1. Extract this folder anywhere (Desktop, USB drive, etc.)
2. Double-click:  start.bat          (opens the AutoDJ desktop GUI)
   Or:            check.bat          (verifies mpv, yt-dlp, folders before starting)

WHAT'S INSIDE
-------------
zAutoDJ.exe   - The music bot (no Python installation needed)
mpv/         - Media player (mpv.exe) + YouTube downloader (yt-dlp.exe)
config.toml  - Edit this to set your admins, music folders, etc.

SYSTEM REQUIREMENTS
-------------------
- Windows 10 or Windows 11
- Camfrog video chat installed and running (for room chat)
- Internet connection (for YouTube song requests)

TROUBLESHOOTING
---------------
- Double-click check.bat first - it tells you if anything is missing.
- If mpv/yt-dlp registration fails, run mpv\mpv-register.bat as administrator.
- Edit config.toml with Notepad to add your nickname as an admin.
