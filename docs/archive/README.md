# Archived reports

Historical plans, audits and verification reports moved here from the repository root to keep the root focused on active project files. Their content is unchanged, and so is their git history (`git log --follow docs/archive/<file>`).

Older documents may still refer to these files by their former root path.

Still at the root on purpose, because tooling reads them:

- **`IMPLEMENTATION-CHECKLIST.md`:** required by `scripts/validate_repo.py` and `scripts/bootstrap.py`.
- **`AUDIT_FINDINGS.md`, `SECURITY_AUDIT_FINDINGS.md`:** written by the `security-audit-fix` skill.

Current release notes: [`CHANGELOG.md`](../../CHANGELOG.md).
