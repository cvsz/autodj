# คู่มือคำสั่ง AutoDJ — ภาษาไทย

**เวอร์ชัน:** 0.2.8  
**คำนำหน้า:** `!` (ปรับได้ใน `config.toml` ผ่าน `prefix`)  
**ภาษา:** ไทย (`lang = "th"`)

1. [คำสั่งทั่วไป](#คำสั่งทั่วไป) — ใช้ได้ทุกคน
2. [คำสั่งสำหรับผู้ขอเพลงและแอดมิน](#คำสั่งสำหรับผู้ขอเพลงและแอดมิน) — ใช้ได้เฉพาะคนขอเพลงและแอดมิน
3. [คำสั่งแอดมิน](#คำสั่งแอดมิน) — ใช้ได้เฉพาะแอดมิน
4. [คำสั่งข้อความส่วนตัว (IM)](#คำสั่งข้อความส่วนตัว-im) — พฤติกรรมพิเศษใน DM

## คำสั่งทั่วไป

| คำสั่ง | อัลลิแอส | คำอธิบาย | รูปแบบการใช้ |
|---------|----------|------------|--------------|
| `help` | `ช่วยเหลือ` | แสดงคำสั่งทั้งหมดที่ใช้ได้ | `!help` |
| `play` | `เล่น`, `ขอเพลง`, `เล่นเพลง` | ขอเพลงผ่าน URL YouTube ค้นหาชื่อ หรือไฟล์ในเครื่อง | `!เล่น <url\|ชื่อเพลง>` |
| `np` | `เพลงนี้` | แสดงเพลงที่กำลังเล่นอยู่ | `!เพลงนี้` |
| `next` | `ถัดไป` | แสดงเพลงถัดไปในคิว | `!ถัดไป` |
| `queue` | `คิว` | แสดงคิวขอเพลง (5 รายการแรก) | `!คิว` |
| `history` | `ประวัติ` | แสดงเพลงที่เล่นไปแล้ว (5 เพลงล่าสุด) | `!ประวัติ` |
| `voteskip` | `โหวตข้าม` | โหวตข้ามเพลงที่กำลังเล่น | `!โหวตข้าม` |
| `remove` | `ลบ` | ลบเพลงที่ตัวเองขอออกจากคิว โดยระบุเลขลำดับ | `!ลบ <เลข>` |
| `last` | `ขอล่าสุด` | แสดง 5 เพลงที่ถูกขอล่าสุด (จาก playlist.json) | `!ขอล่าสุด` |

### ตัวอย่าง

```
!เล่น https://www.youtube.com/watch?v=dQw4w9WgXcQ
!เล่น never gonna give you up
!เล่น despacito
!เพลงนี้
!ถัดไป
!คิว
!ประวัติ
!โหวตข้าม
!ลบ 2
!ขอล่าสุด
```

## คำสั่งแอดมิน

| คำสั่ง | อัลลิแอส | คำอธิบาย | รูปแบบการใช้ |
|---------|----------|------------|--------------|
| `pause` | `หยุดชั่วคราว` | หยุดการเล่นชั่วคราว | `!หยุดชั่วคราว` |
| `resume` | `เล่นต่อ` | เล่นต่อจากที่หยุด | `!เล่นต่อ` |
| `vol` | `เสียง` | ตั้งระดับเสียง (0-100) หรือดูค่าปัจจุบัน | `!เสียง [0-100]` |
| `shuffle` | `สุ่ม` | เปิด/ปิดโหมดสุ่มเพลง | `!สุ่ม on\|off` |
| `repeat` | `วนซ้ำ` | ตั้งโหมดวนซ้ำ | `!วนซ้ำ off\|one` |
| `clear` | `ล้างคิว` | ล้างคิวขอเพลงทั้งหมด | `!ล้างคิว` |

| `deletehistory` | `ลบประวัติ` | ลบรายการในประวัติ | `!ลบประวัติ all\|<N>` |
| `load` | `โหลด` | โหลดเพลย์ลิสต์/โฟลเดอร์/ไฟล์ เข้าสู่ระบบเล่นอัตโนมัติ | `!โหลด <แหล่ง>` |
| `say` | `พูด` | ส่งข้อความไปยังแชทห้อง | `!พูด <ข้อความ>` |

| `unblock` | `เลิกบล็อก` | ยกเลิกการบล็อกผู้ใช้ | `!เลิกบล็อก <ชื่อ>` |

## คำสั่งข้อความส่วนตัว (IM / Private Message)

### กฎพิเศษสำหรับ IM/DM

1. **ไม่ต้องใส่คำนำหน้า** — พิมพ์คำสั่งโดยตรงไม่ต้องใส่ `!`
2. **คำสั่งขอเพลงใช้ได้เฉพาะ IM** — ผู้ใช้ทั่วไปต้องส่งขอเพลงผ่านข้อความส่วนตัวเท่านั้น
3. **ต้องอยู่ในห้อง** — ต้องปรากฏในแชทห้อง (เคยพูดในห้อง) ถึงจะใช้คำสั่ง IM ได้
4. **คูลดาวน์ยังทำงาน** — จำกัดอัตราการใช้งานและคูลดาวน์ยังคงบังคับใช้
5. **แอดมินใช้คำสั่งได้** — แอดมินสามารถใช้คำสั่งแอดมินผ่าน IM ได้

### ตัวอย่างคำสั่ง IM

```
เล่น never gonna give you up
ขอเพลง despacito
เล่นเพลง Bohemian Rhapsody
เพลงนี้
ถัดไป
คิว
ประวัติ
โหวตข้าม
ลบ 2
ขอล่าสุด
ช่วยเหลือ
```

### แอดมินผ่าน IM

```
หยุดชั่วคราว
เล่นต่อ
เสียง 80
สุ่ม on
วนซ้ำ one
ล้างคิว
โหลด https://youtube.com/playlist?list=...
พูด แอดมินพูด!
ออกเสียง ประกาศจากแอดมิน
บล็อก user123
เลิกบล็อก user123
```

## ขีดจำกัดและคูลดาวน์

| การตั้งค่า | ค่าเริ่มต้น | คำอธิบาย |
|------------|------------|-----------|
| `cooldown` | 3.0 วินาที | เวลาขั้นต่ำระหว่างคำสั่งจากผู้ใช้คนเดียว |
| `max_requests_per_user` | 3 เพลง | จำนวนเพลงสูงสุดในคิวต่อผู้ใช้ |
| `user_request_limit` | 5 ครั้ง | จำนวนคำขอสูงสุดต่อผู้ใช้ในช่วงเวลาลื่น |
| `rate_limit_window` | 300 วินาที | ช่วงเวลาลื่นสำหรับจำกัดอัตราคำขอ |
| `max_duration` | 900 วินาที | ความยาวเพลงสูงสุดสำหรับผู้ใช้ทั่วไป |
| `max_queue` | 50 รายการ | จำนวนคำขอสูงสุดในคิวทั้งหมด |

## พฤติกรรมการเล่นอัตโนมัติ (Autoplay)

- **หมดเวลาว่าง:** 30 วินาที (ปรับได้: `autoplay_idle_timeout`)
- เมื่อไม่มีการขอเพลงจากผู้ใช้ครบเวลาที่กำหนด บอทจะสลับไปเล่นจากสระเพลงอัตโนมัติ
- การขอเพลงใหม่จากผู้ใช้จะออกจากโหมดอัตโนมัติทันที
- สระเพลงอัตโนมัติมาจาก: `music_dirs`, `autoplay_sources`, `playlist.json`

## การตั้งค่าสำคัญ (config.toml)

```toml
# หลัก
prefix = "!"
lang = "th"
bot_nick = "AutoDJ"
admins = ["admin_nick"]  # ไม่สนใจตัวพิมพ์เล็ก/ใหญ่

# แชท
chat_reader = "uia"
chat_sender = "uia"
auto_discover = true

# เสียง
mpv_path = "mpv"
ytdlp_path = ""
audio_device = ""
volume = 70

# คลังเพลง
music_dirs = ["D:/Music"]
autoplay_sources = []
shuffle = true

# ขีดจำกัด
max_requests_per_user = 3
max_queue = 50
max_duration = 900
voteskip_threshold = 3
cooldown = 3.0
send_interval = 1.5

# ฟีเจอร์
playlist_file = "playlist.json"
search_limit = 1
mpv_timeout = 30

# ใหม่ใน 0.2.8
autoplay_idle_timeout = 30.0
admin_greeting_enabled = false
admin_greeting_message = "สวัสดีครับแอดมิน {admin} ยินดีต้อนรับกลับมา!"
admin_greeting_cooldown = 3600.0
im_require_room_presence = true

# สไตล์ข้อความ (เฉพาะแสดงผลใน GUI - Camfrog ส่งเป็น plain text เท่านั้น)
message_style = { font_family = "Consolas", font_size = 14, font_color = "#FF0000", bold = false, italic = false, underline = false }
```

## หมายเหตุ

- **ไม่สนใจตัวพิมพ์:** ชื่อคำสั่งและชื่อแอดมิน ไม่แยกตัวพิมพ์เล็ก/ใหญ่
- **ไทย/อังกฤษ:** สลับภาษาได้ใน GUI หรือตั้ง `lang = "en"` ใน config
- **ความปลอดภัย IM:** คำสั่งข้อความส่วนตัวต้องมีผู้ใช้อยู่ในแชทห้อง
- **จำกัดอัตรา:** ใช้ sliding window กันสแปม; คูลดาวน์กันคำสั่งติดต่อกัน
- **กันซ้ำ:** เพลงซ้ำไม่จะเข้าคิวซ้ำ
- **แอดมิน fail-closed:** รายการแอดมินว่าง = ไม่มีสิทธิ์แอดมินผ่านชื่อเล่น
