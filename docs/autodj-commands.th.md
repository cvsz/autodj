**เวอร์ชัน:** 0.3.21

## คำสั่งทั่วไป

| คำสั่ง | อัลลิแอส | คำอธิบาย | รูปแบบการใช้ |
|---------|----------|------------|--------------|
| `help` | `ช่วยเหลือ` | แสดงคำสั่งทั้งหมดที่ใช้ได้ | `!help` |
| `play` | `เล่น`, `ขอเพลง`, `เล่นเพลง` | ขอเพลงผ่าน URL YouTube ค้นหาชื่อ หรือไฟล์ในเครื่อง | `!เล่น <url\|ชื่อเพลง>` |
| `np` | `เพลงนี้` | แสดงเพลงที่กำลังเล่นอยู่ พร้อมเวลาที่เล่นไปแล้ว `(เล่นไป/ความยาว)` | `!เพลงนี้` |
| `next` | `ถัดไป` | แสดงเพลงถัดไปในคิว | `!ถัดไป` |
| `queue` | `คิว` | แสดงคิวขอเพลง (5 รายการแรก) | `!คิว` |
| `history` | `ประวัติ` | แสดงเพลงที่เล่นไปแล้ว (5 เพลงล่าสุด) | `!ประวัติ` |
| `voteskip` | `โหวตข้าม` | โหวตข้ามเพลงที่กำลังเล่น | `!โหวตข้าม` |
| `remove` | `ลบ` | ลบเพลงที่ตัวเองขอออกจากคิว โดยระบุเลขลำดับ | `!ลบ <เลข>` |
| `last` | `ขอล่าสุด` | แสดง 5 เพลงที่ถูกขอล่าสุด (จาก playlist.json) | `!ขอล่าสุด` |

### ตัวอย่าง

```
!ถัดไป
!คิว

!โหวตข้าม
!ลบ 2
!ขอล่าสุด
```

## คำสั่งข้อความส่วนตัว (IM / Private Message)

### กฎพิเศษสำหรับ IM/DM

1. **ไม่ต้องใส่คำนำหน้า** — พิมพ์คำสั่งโดยตรงไม่ต้องใส่ `!`
2. **คำสั่งขอเพลงใช้ได้เฉพาะ IM** — ผู้ใช้ทั่วไปต้องส่งขอเพลงผ่านข้อความส่วนตัวเท่านั้น
3. **ต้องอยู่ในห้อง** — ต้องปรากฏในแชทห้อง (เคยพูดในห้อง) ถึงจะใช้คำสั่ง IM ได้
4. **คูลดาวน์ยังทำงาน** — จำกัดอัตราการใช้งานและคูลดาวน์ยังคงบังคับใช้
5. **แอดมินใช้คำสั่งได้** — แอดมินสามารถใช้คำสั่งแอดมินผ่าน IM ได้

### ตัวอย่างคำสั่ง IM

```
เล่น never gonna give you up
ขอเพลง despacito
เล่นเพลง Bohemian Rhapsody
เพลงนี้
ถัดไป
คิว
ประวัติ
โหวตข้าม
ลบ 2
ขอล่าสุด
ช่วยเหลือ
```

### แอดมินผ่าน IM

```
หยุดชั่วคราว
เล่นต่อ
เสียง 80
สุ่ม on
วนซ้ำ one
ล้างคิว
โหลด https://youtube.com/playlist?list=...
พูด แอดมินพูด!
ออกเสียง ประกาศจากแอดมิน
บล็อก user123
เลิกบล็อก user123
```

## รายละเอียดคำสั่ง IM

### /aplay (ชื่อเรียกสั้น: /addm)

ขอเพลงผ่าน IM ทำงานเหมือนกับ `!play` แต่ไม่ต้องใส่คำนำหน้า `!`

**ตัวอย่าง:**
```
/aplay https://www.youtube.com/watch?v=dQw4w9WgXcQ
/aplay never gonna give you up
/aplay despacito
```

### /aplay fav <n> (alias: /ขอล่าสุด)

เล่นเพลงโปรดตามลำดับที่ระบุ (เริ่มนับที่ 1) จากเพลงโปรดของคุณ ดูได้ด้วย `/myfavp`

**ตัวอย่าง:**
```
/aplay fav 1
/aplay fav 3
```

### /nowp (ชื่อเรียกสั้น: /เพลงนี้)

แสดงเพลงที่กำลังเล่นอยู่ ผู้ที่ขอ และเวลาที่เล่นไปแล้ว เช่น `กำลังเล่น: X [3:20] - ขอโดย bob (1:05/3:20)`

**ตัวอย่าง:**
```
/nowp
```

### /skipp (ชื่อเรียกสั้น: /ข้ามเพลง)

ข้ามเพลงที่กำลังเล่น อนุญาตเฉพาะผู้ที่ขอเพลงหรือแอดมินเท่านั้น

**ตัวอย่าง:**
```
/skipp
```

### /lastp (ชื่อเรียกสั้น: /ขอล่าสุด)

แสดงเพลงที่เล่นไป 5 เพลงล่าสุด

**ตัวอย่าง:**
```
/lastp
```

### /hbdp (ชื่อเรียกสั้น: /hbdm)

อวยพรวันเกิดในห้องและเปิดเพลงวันเกิด

**ตัวอย่าง:**
```
/hbdp kris
/hbdp สมชาย
```

### /topp (ชื่อเรียกสั้น: /topm)

แสดงเพลงที่ถูกขอมากที่สุดในวันนี้หรือสัปดาห์นี้

**ตัวอย่าง:**
```
/topp
/topp week
```

### /favp (ชื่อเรียกสั้น: /favm)

บันทึกเพลงที่กำลังเล่นอยู่ในเพลงโปรด

**ตัวอย่าง:**
```
/favp
```

### /myfavp (ชื่อเรียกสั้น: /myfavm)

ดูเพลงโปรดที่บันทึกไว้ของคุณ

**ตัวอย่าง:**
```
/myfavp
```

### /hadj (ชื่อเรียกสั้น: /helpm, /คู่มือ)

แสดงคู่มือคำสั่งทั้งหมด (ทั้งสองหน้า) ส่งเป็น IM ถึงบอท

**ตัวอย่าง:**
```
/hadj
```

## พฤติกรรมการเล่นอัตโนมัติ (Autoplay)

- **หมดเวลาว่าง:** 30 วินาที (ปรับได้: `autoplay_idle_timeout`)
- เมื่อไม่มีการขอเพลงจากผู้ใช้ครบเวลาที่กำหนด บอทจะสลับไปเล่นจากสระเพลงอัตโนมัติ
- การขอเพลงใหม่จากผู้ใช้จะออกจากโหมดอัตโนมัติทันที
- สระเพลงอัตโนมัติมาจาก: `music_dirs`, `autoplay_sources`, `playlist.json`
- สระเพลงวนเล่นไปเรื่อย ๆ ไม่หมดหลังเล่นครบรอบ ถ้า `shuffle = true` จะสุ่มแบบ "ถุงสุ่ม" คือไม่เล่นเพลงซ้ำจนกว่าจะเล่นครบทุกเพลงในสระ
- เพลงที่ประกาศว่า "เพลงถัดไป" จะเป็นเพลงที่เล่นต่อจริงเสมอ
- ประกาศ "กำลังเล่น" ครั้งเดียวต่อเพลง แม้เปิด `!วนซ้ำ one`

## ตอบคำถาม "เพลงอะไร" อัตโนมัติ

ไม่ต้องพิมพ์คำสั่ง: เมื่อมีคนในห้องพิมพ์ข้อความที่มีคำใน `np_question_keywords` (ไม่สนตัวพิมพ์เล็ก/ใหญ่ เช่น "เพลงอะไร", "เพลงชื่ออะไร", "ชื่อเพลง", "what song", "what's playing") บอทจะตอบด้วยข้อความเดียวกับ `!เพลงนี้` ข้อความที่ขึ้นต้นด้วย prefix คำสั่งจะไม่นับ มีคูลดาวน์ทั้งห้อง (`np_question_cooldown` ค่าเริ่มต้น 20 วินาที) กันบอทตอบรัวเวลามีหลายคนถามพร้อมกัน ปิดได้ด้วย `np_question_reply = false` หรือในหน้าตั้งค่าของ GUI

```toml

lang = "th"
bot_nick = "AutoDJ"
admins = ["admin_nick"]  # ไม่สนใจตัวพิมพ์เล็ก/ใหญ่

# แชท
chat_reader = "uia"
chat_sender = "uia"
auto_discover = true

# เสียง
mpv_path = "mpv"
ytdlp_path = ""
audio_device = ""
volume = 70

# คลังเพลง
music_dirs = ["D:/Music"]
autoplay_sources = []
shuffle = true

# ขีดจำกัด
max_requests_per_user = 3
max_queue = 50
max_duration = 900
voteskip_threshold = 3
cooldown = 3.0
send_interval = 1.5

# ฟีเจอร์
playlist_file = "playlist.json"
search_limit = 1
mpv_timeout = 30

# การประกาศ
announce_next = true
np_question_reply = true            # ตอบ "เพลงอะไร" โดยไม่ต้องใช้คำสั่ง
np_question_keywords = ["เพลงอะไร", "เพลงไร", "เพลงชื่อ", "ชื่อเพลง", "เพลงนี้ชื่อ", "what song", "whats playing", "what's playing", "song name"]
np_question_cooldown = 20.0         # วินาที ใช้ร่วมทั้งห้อง (0-3600)
msg_now = ""                        # "" = ข้อความในตัว; ฟิลด์ {title} {duration} {requester} {elapsed} {remaining} {eta}
```

## หมายเหตุ

- **ไม่สนใจตัวพิมพ์:** ชื่อคำสั่งและชื่อแอดมิน ไม่แยกตัวพิมพ์เล็ก/ใหญ่
- **ไทย/อังกฤษ:** สลับภาษาได้ใน GUI หรือตั้ง `lang = "en"` ใน config
- **ความปลอดภัย IM:** คำสั่งข้อความส่วนตัวต้องมีผู้ใช้อยู่ในแชทห้อง
- **จำกัดอัตรา:** ใช้ sliding window กันสแปม; คูลดาวน์กันคำสั่งติดต่อกัน
- **กันซ้ำ:** เพลงซ้ำไม่จะเข้าคิวซ้ำ
- **แอดมิน fail-closed:** รายการแอดมินว่าง = ไม่มีสิทธิ์แอดมินผ่านชื่อเล่น

## กติกาการขอเพลงและเพลงเริ่มต้น

- **เพลงเริ่มต้น** (`default_track` ใน config.toml หรือหน้า Settings) เล่นทันทีเมื่อเปิดโปรแกรม
- **คนแรกที่ขอเพลง** ตัดเพลงเริ่มต้น/เพลงอัตโนมัติ แล้วเล่นเพลงที่ขอ **ทันที**
- **คนถัดไปที่ขอ** เข้าคิวตามลำดับก่อน-หลัง (FIFO) โดยเพลงที่กำลังเล่นซึ่งมีคนขอ **ไม่ถูกตัด** เล่นจนจบเสมอ
- เมื่อคิวหมดและ **ไม่มีคนขอเพลงภายใน `autoplay_idle_timeout` (ค่าเริ่มต้น 30 วินาที) นับจากเพลงที่ขอเพลงสุดท้ายเล่นจบ** จะกลับไปเล่นเพลงเริ่มต้น (เล่นซ้ำไปเรื่อย ๆ จนมีคนขอใหม่)
- ถ้าลิงก์เพลงเริ่มต้นเล่นไม่ได้ ระบบใช้เพลงจากคลังอัตโนมัติแทน 10 นาที

### ขอเพลงในห้องหรือทาง IM

- `allow_play_in_room = true` (ค่าเริ่มต้น) → ขอเพลงได้ทั้งในแชทห้องและทาง IM; `false` → ขอได้เฉพาะทาง IM (บอทตอบในห้องว่าให้ส่ง IM) การขอทาง IM ต้องอยู่ในห้องเสมอ
- `im_require_room_presence = true` → รับคำสั่งทาง IM เฉพาะคนที่เคยพิมพ์ในห้องแล้ว คนอื่นจะได้รับข้อความส่วนตัวว่า "กรุณาเข้าห้อง camfrog:join:{room} ก่อนขอเพลงครับ" (ตั้งค่าได้ที่ `im_join_room_message`)
- ทาง IM จะพิมพ์มีหรือไม่มีเครื่องหมายนำหน้าก็ได้ เช่น `np` หรือ `!np`
- จำกัดการขอเพลงต่อคน (`user_request_limit` ใน `rate_limit_window`) ใช้กับทุกชื่อคำสั่งขอเพลง (play, เล่น, ขอเพลง, เล่นเพลง, เปิดเพลง, aplay, addm, hbdp)
