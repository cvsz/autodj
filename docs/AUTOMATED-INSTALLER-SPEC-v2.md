## 🐛 Critical Bugs Fixed

### 1. `install.bat` - Windows Version Parsing (FIXED)
```batch
REM BROKEN (original):
for /f "tokens=3" %%a in ('ver') do set WINVER=%%a
REM Output: "Microsoft Windows [Version 10.0.26300.9807]"
REM tokens=3 captures "[Version" → BUILD="" → "22000 was unexpected at this time"

REM FIXED:
for /f "tokens=4" %%a in ('ver') do set WINVER=%%a
for /f "tokens=3 delims=." %%b in ("%WINVER%") do set BUILD=%%b
set BUILD=%BUILD:]=%
```
**Root cause:** `ver` output format is `Microsoft Windows [Version 10.0.26300.9807]` - token 4 = `10.0.26300.9807]`

### 2. `install.ps1` - Unicode Encoding Issues (FIXED IN SPEC)
**Problem:** PowerShell 5.1 cannot parse Unicode chars (✓ ⚠ ✗ →) in script literals.

**Solution:** Replace all Unicode with ASCII equivalents in the actual script file:
| Unicode | ASCII Replacement |
|---------|-------------------|
| `✓` | `[OK]` |
| `⚠` | `[WARN]` |
| `✗` | `[FAIL]` |
| `→` | `->` |
| `═` | `=` |
| `│` | `|` |

### 3. Missing Files for NSIS Build
**Required in `dist/` before running `build_installer.bat`:**
```
dist/
├── AutoDJ.exe           ← Built by build.ps1
├── app.ico              ← Copy from root
├── config.example.toml  ← Copy from root

```


## 🔧 Installation Path 1: Interactive PowerShell (`install.ps1`)

### Usage
```powershell
# Default interactive install
.\install.ps1

# Custom directory with auto-start
.\install.ps1 -ProjectDir "D:\AutoDJ" -AutoStart -Verbose

# Skip build (use pre-built exe), force reinstall deps
.\install.ps1 -NoBuild -Force

# Skip VB-Cable (install manually later)
.\install.ps1 -SkipVBCable
```

### Parameters
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `ProjectDir` | string | `$env:USERPROFILE\CamfrogAutoDJ` | Install directory |
| `NoBuild` | switch | false | Skip PyInstaller build |
| `NoShortcuts` | switch | false | Skip Desktop/Start Menu shortcuts |
| `AutoStart` | switch | false | Create Startup folder shortcut |
| `PythonVersion` | string | `"3.11"` | Minimum Python version |
| `GitBranch` | string | `"main"` | Git branch to clone |
| `Verbose` | switch | false | Detailed output |
| `Force` | switch | false | Force reinstall |
| `SkipVBCable` | switch | false | Skip VB-Cable prompt |

### What It Does (10 Steps)
```
1. CHECK WINDOWS 11     → Build ≥ 22000 (via Get-CimInstance)
2. CHECK DEPENDENCIES   → Python, mpv, yt-dlp, VB-Cable
3. INSTALL MISSING      → winget → pip → manual download
4. SETUP PROJECT        → git clone --depth 1
5. INSTALL PYTHON DEPS  → pip install -e .[build,dev]
6. BUILD EXE            → .\build.ps1 (PyInstaller + sign)
7. CREATE CONFIG        → config.example.toml → config.toml (interactive)
8. CREATE SHORTCUTS     → Desktop, Start Menu, Config, Uninstall
9. AUTO-START (opt)     → Startup folder shortcut
10. VERIFY              → AutoDJ.exe --check
```

### Output Locations
```
%USERPROFILE%\CamfrogAutoDJ\
├── dist\AutoDJ.exe           # Main executable
├── config.toml               # User configuration
├── uninstall.ps1             # Generated uninstaller
├── camfrog_autodj\           # Python source
└── (other project files)

Shortcuts:
├── Desktop\Camfrog AutoDJ.lnk
├── Start Menu\Programs\Camfrog AutoDJ\Camfrog AutoDJ.lnk
├── Start Menu\Programs\Camfrog AutoDJ\Edit Config.lnk
├── Start Menu\Programs\Camfrog AutoDJ\Uninstall.lnk
```

## 🏗️ Build Process: AutoDJ.exe (PyInstaller)

### build.ps1 - The Master Build Script
```powershell
# Build + self-sign (default)
.\build.ps1

# Clean build (after icon/version/options change)
.\build.ps1 -Clean

# Build only (no signing)
.\build.ps1 -NoSign

# Sign with purchased certificate
.\build.ps1 -Pfx "cert.pfx" -Password "xxx"

# Sign with cert in store
.\build.ps1 -Thumbprint "ABC123..."
```

### PyInstaller Configuration (from build.ps1)
```powershell
$pyi = @(
    "--noconfirm",
    "--onefile",                    # Single executable
    "--noupx",                      # No UPX (fewer AV false positives)
    "--name", "AutoDJ",
    "--icon", "app.ico",
    "--version-file", "version_info.txt",
    "--add-data", "app.ico;.",      # Include icon in exe
    "--collect-submodules", "camfrog_autodj",
    "--collect-submodules", "pywinauto",
    "--collect-submodules", "pyttsx3",
    "--collect-all", "yt_dlp",      # All yt-dlp extractors
    "--hidden-import", "comtypes",
    "--hidden-import", "pyperclip",
    "--hidden-import", "mutagen",
    "run_autodj.py"
)
python -m PyInstaller @pyi
```

### version_info.txt (Single Version Source)
```txt
# UPDATE THIS FILE FOR VERSION CHANGES
VSVersionInfo(
  ffi=FixedFileInfo(
    filevers=(0, 2, 3, 0),      # Major, Minor, Patch, Build
    prodvers=(0, 2, 3, 0),
    ...
  ),
  kids=[
    StringFileInfo([StringTable('040904B0', [
      StringStruct('FileVersion', '0.2.3.0'),
      StringStruct('ProductVersion', '0.2.3.0'),
      StringStruct('CompanyName', 'ZEAZDEV COMPANY LIMITED'),
      StringStruct('LegalCopyright', 'Copyright (c) ZEAZDEV COMPANY LIMITED'),
      StringStruct('OriginalFilename', 'AutoDJ.exe'),
      StringStruct('ProductName', 'AutoDJ'),
    ])]),
    VarFileInfo([VarStruct('Translation', [1033, 1200])])
  ]
)
```

### Version Update Checklist
When bumping version (e.g., 0.2.4 → 0.2.5):
- [ ] `version_info.txt` - `filevers=(0,2,5,0)`, `prodvers=(0,2,5,0)`, `FileVersion='0.2.5.0'`, `ProductVersion='0.2.5.0'`

## 🔐 Code Signing

### Development (Self-Signed)
- Automatic via `build.ps1` if no cert provided
- Creates `cert/autodj-codesign.cer`
- Imports to `CurrentUser\Root` + `CurrentUser\TrustedPublisher`
- **Only trusted on build machine**

### Production (Real Certificate)
```powershell
# Option 1: PFX file
.\build.ps1 -Pfx "cert.pfx" -Password "xxx"

# Option 2: Certificate in Windows Store
.\build.ps1 -Thumbprint "ABC123DEF456..."

# Sign installer separately
signtool sign /f cert.pfx /p "xxx" /t http://timestamp.digicert.com "Camfrog-AutoDJ-Setup-0.2.3.exe"
```

### Timestamp Servers (tried in order)
1. `http://timestamp.digicert.com`
2. `http://timestamp.sectigo.com`
3. `http://timestamp.globalsign.com/tsa/r6advanced1`

### Verify Signature
```powershell
Get-AuthenticodeSignature dist\AutoDJ.exe | Format-List
# Status should be "Valid" (or "Valid" with warning for self-signed)
```

### uninstall.ps1 Template (Place in dist/)
```powershell
<#
.SYNOPSIS
    Camfrog AutoDJ Uninstaller (Generated)
#>
param([switch]$Force)

$InstallDir = "$env:PROGRAMFILES64\Camfrog AutoDJ"
$ErrorActionPreference = "Continue"

Write-Host "Uninstalling Camfrog AutoDJ..." -ForegroundColor Cyan

# Remove shortcuts
$startMenu = Join-Path $env:APPDATA "Microsoft\Windows\Start Menu\Programs"
$autoDjFolder = Join-Path $startMenu "Camfrog AutoDJ"
if (Test-Path $autoDjFolder) { Remove-Item -Recurse -Force $autoDjFolder; Write-Host "Removed Start Menu folder" }

$desktop = [Environment]::GetFolderPath("Desktop")
$desktopShortcut = Join-Path $desktop "Camfrog AutoDJ.lnk"
if (Test-Path $desktopShortcut) { Remove-Item -Force $desktopShortcut; Write-Host "Removed Desktop shortcut" }

$startup = Join-Path $env:APPDATA "Microsoft\Windows\Start Menu\Programs\Startup"
$autoStartShortcut = Join-Path $startup "Camfrog AutoDJ.lnk"
if (Test-Path $autoStartShortcut) { Remove-Item -Force $autoStartShortcut; Write-Host "Removed auto-start shortcut" }

# Remove registry
$regPaths = @(
    "HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\CamfrogAutoDJ",
    "HKLM:\Software\Microsoft\Windows\CurrentVersion\App Paths\AutoDJ.exe",
    "HKLM:\Software\CamfrogAutoDJ"
)
foreach ($p in $regPaths) { if (Test-Path $p) { Remove-Item -Recurse -Force $p; Write-Host "Removed registry: $p" } }

# Remove install directory
if ($Force -or (Read-Host "Remove $InstallDir? [y/N]" -eq "y")) {
    if (Test-Path $InstallDir) { Remove-Item -Recurse -Force $InstallDir; Write-Host "Removed $InstallDir" }
}

Write-Host "Uninstall complete." -ForegroundColor Green
Read-Host "Press Enter to exit"
```

## 🛠️ Troubleshooting Guide

### "NSIS not found" / "not was unexpected at this time"
```powershell
winget install NSIS.NSIS
# RESTART TERMINAL COMPLETELY
where makensis  # Should show path
```

### "Python not found after install"
```powershell
# Refresh PATH from registry
$env:PATH = [Environment]::GetEnvironmentVariable("PATH","Machine") + ";" + [Environment]::GetEnvironmentVariable("PATH","User")
python --version
```

### "VB-Cable audio not working"
1. Run `install.ps1` as Administrator (or install manually from https://vb-audio.com/Cable/)
2. **REBOOT REQUIRED** after VB-Cable install
3. Find device name: `mpv --audio-device=help`
4. Set in `config.toml`: `audio_device = "CABLE Output (VB-Audio Virtual Cable)"`

### "Access denied" during signing
- Run PowerShell as Administrator
- Ensure cert has Code Signing EKU (1.3.6.1.5.5.7.3.3)
- Check `signtool` in PATH (Windows 10 SDK)

### "Unicode parse errors" in install.ps1 (PowerShell 5.1)
Replace Unicode chars in script:
```powershell
# Find/replace in install.ps1:
'✓' → '[OK]'
'⚠' → '[WARN]'
'✗' → '[FAIL]'
'→'  → '->'
'═'  → '='
'│'  → '|'
```

### "Installer.nsi: File not found" errors
Ensure all required files exist in `dist/` before building:
```powershell
ls dist\AutoDJ.exe, dist\app.ico, dist\config.example.toml, dist\README.md, dist\CHANGELOG.md, dist\LICENSE.md, dist\install.ps1, dist\uninstall.ps1, dist\run_autodj.py
```

## 🔄 Maintenance Procedures

### Adding a New Dependency
1. Add to `install.ps1`:
   - `Check-<Name>` function
   - `Install-<Name>` function
   - Call in Main() after existing checks
2. Add to `build.ps1` PyInstaller args if needed (`--hidden-import`, `--collect-submodules`)
3. Update `config.example.toml` if config needed
4. Update this document

### Updating Python Version
1. Update `PythonVersion` default in `install.ps1` param block
2. Update winget ID in `Install-Python` (e.g., `Python.Python.3.12`)
3. Update `build.ps1` if PyInstaller compatibility changes
4. Test on clean VM

### Changing Install Directory (NSIS)
Edit `installer.nsi`:
```nsis
InstallDir "$PROGRAMFILES64\Camfrog AutoDJ"  ; Change here
InstallDirRegKey HKLM "Software\CamfrogAutoDJ" "InstallDir"
```
Also update registry paths in Uninstall section.
